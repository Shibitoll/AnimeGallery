AnimeGallery — Інформаційна вебсистема каталогізації аніме-контенту

Development of the Information Web System for Anime Content Cataloging

Короткий опис

Проєкт присвячений створенню інтелектуальної вебплатформи для систематизації аніме-індустрії. Система забезпечує зручний пошук, модерацію та формування персональних списків користувачів.

Мета дослідження

Проєктування та розробка функціональної інформаційної вебсистеми, що оптимізує процес управління медіаконтентом та персоналізацію досвіду шанувальників аніме.

Основні завдання

  • Провести системний аналіз предметної області.
  • Спроєктувати архітектуру реляційної бази даних.
  • Розробити інтерактивний інтерфейс на базі React.
  • Реалізувати серверне API засобами Django.

Очікувані результати

Діючий вебсервіс із сучасним UX/UI, підтримкою модерації та інтеграцією зовнішніх API даних.
