Інформаційна вебсистема каталогізації аніме-контенту

Comprehensive Information System for Anime Content Management

Короткий опис (Анотація)

AnimeGallery — інтелектуальна вебсистема каталогізації та модерації аніме-контенту. Забезпечує користувачів інструментами для створення персональних медіатек, оцінювання та інтерактивної взаємодії, вирішуючи проблему фрагментації даних у сучасному медіапросторі.

Актуальність дослідження

Основна проблема медіапростору в контексті аніме-індустрії полягає у високій розпорошеності інформаційних активів. Користувачі звертаються до десятків непов'язаних джерел із неповними даними. Відсутність єдиної системи модерації призводить до дублювання інформації. Водночас зростає попит на інтерактивні платформи, які здатні забезпечити колективне оцінювання та гнучке налаштування персональних бібліотек.

Мета дослідження

Теоретичне обґрунтування, проєктування та практична реалізація інформаційної вебсистеми каталогізації та оцінювання аніме-контенту. Продукт має стати ефективним інструментом для централізованого управління колекціями та створення безпечного середовища для комунікації в межах спеціалізованої спільноти.

Основні завдання

  • Аналітичний етап: Дослідження потреб цільової аудиторії та критичний аналіз існуючих програмних рішень.
  • Функціональне проєктування: Визначення ключових модулів: автентифікації, багатокритеріального пошуку та модерації.
  • Архітектурне моделювання: Розробка логічної структури системи та схеми реляційної бази даних PostgreSQL.
  • Інтерфейсне проєктування: Створення прототипів графічного інтерфейсу (UX/UI) з урахуванням стандартів доступності.
  • Програмна реалізація: Написання вихідного коду клієнтської та серверної частин та забезпечення їхньої взаємодії через API.

Методологія дослідження

  • Системний аналіз: застосовано для дослідження предметної області та формування технічних вимог.
  • Порівняльний аналіз: використано для експертного вибору оптимального стеку технологій.
  • Реляційне моделювання: застосовано для проєктування структури бази даних та уникнення дублювання.
  • Компонентно-орієнтоване проєктування: використано для створення модульної архітектури інтерфейсу на React.

Технологічний стек

  • Frontend: React 19 (Vite) + Tailwind CSS — забезпечення миттєвого оновлення інтерфейсу без перезавантаження.
  • Backend: Django REST Framework (Python) — реалізація бізнес-логіки та безпечної обробки даних (патерн MTV).
  • Database: PostgreSQL — об'єктно-реляційна система для ефективного зберігання великих масивів метаданих.

Структура програмного проєкту

Проєкт проєктується за принципом розділеної архітектури (Decoupled Architecture) на базі клієнт-серверної моделі. Файлова структура репозиторію організована наступним чином:

/backend
Серверна частина додатка на базі фреймворку Django.
/frontend
Клієнтська частина на React (Single Page Application).
/frontend/src/api
Сервіси для взаємодії з серверним API (налаштування Axios/Fetch).
/frontend/src/components
Модульні UI-компоненти, макети та сторінки застосунку.
/landing
Презентаційна сторінка проєкту для документування етапів розробки.

Очікувані результати

Діючий, високопродуктивний вебсервіс, який успішно вирішує проблему фрагментації даних. Запровадження системи дозволить користувачам формувати надійні персональні бібліотеки, а адміністраторам — ефективно контролювати якість інформаційного наповнення. Очікується значне підвищення рівня залученості аудиторії.

Встановлення та запуск

bash

# 1. Клонування репозиторію

git clone https://github.com/Shibitoll/AnimeGallery.git


# 2. Запуск Backend (Django)

cd AnimeGallery/backend && python -m venv venv

source venv/bin/activate # Windows: venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate && python manage.py runserver


# 3. Запуск Frontend (React) у новому терміналі

cd ../frontend && npm install && npm run dev
